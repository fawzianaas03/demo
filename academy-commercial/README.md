# الأكاديمية الليبية للقرآن وعلومه — Cinematic Commercial

An editable Remotion (React + TypeScript) project for a ~90-second cinematic commercial for
**الأكاديمية الليبية للقرآن وعلومه**, under the leadership of **الأستاذة كريمة النعاس**. It renders
a 1920×1080 master, a 1080×1920 vertical cut and an optional 3840×2160 master, with Arabic SRT
subtitles and a loudness-normalised soundtrack.

| | |
|---|---|
| Duration | 92 s (2208 frames @ 24 fps) |
| Compositions | `AcademyCommercial` (16:9), `AcademyCommercialVertical` (9:16), one standalone composition per scene and ratio (`S01-16x9` … `S09-9x16`) |
| Output | `out/academy-commercial-1080p.mp4`, `out/academy-commercial-vertical-1080x1920.mp4`, optional `out/academy-commercial-4k.mp4` |
| Docs | [`storyboard/`](storyboard): production plan, Arabic script, storyboard with real frames, AI prompts, voice-over script, asset inventory, QC report |

## Quick start

```bash
npm install
npm run dev               # Remotion Studio: preview and scrub every scene
npm run render            # 1080p + vertical → out/ (loudness-normalised)
npm run render:4k         # also the 3840×2160 master
npm run srt               # Arabic subtitles → deliverables/academy-commercial.ar.srt
npm run keyframes         # storyboard stills → storyboard/frames/
npm run sound             # regenerate ambience + SFX stems (needs python3, numpy, scipy)
```

Requirements: Node 20.19+ / 22.13+, FFmpeg on `PATH`, Python 3 with numpy/scipy (only for `npm run sound`).
Remotion downloads its own headless Chrome on first render. In sandboxes that cannot download it,
point `REMOTION_BROWSER_EXECUTABLE` at an installed Chrome Headless Shell:

```bash
REMOTION_BROWSER_EXECUTABLE=/path/to/headless_shell npm run render
```

Render options: `CAPTIONS=false npm run render` renders without burned-in captions;
`CONCURRENCY=8 npm run render` sets parallel browser tabs.

## Customising

All copy and switches live in `src/data/`. Scenes contain no hard-coded wording.

| To change… | Edit |
|---|---|
| Academy name, leadership, slogan, CTA, program names | `src/data/academy.ts` |
| **Telegram link / QR on the end screen** | `src/data/academy.ts` → `telegramUrl: "https://t.me/…"` (a sharp QR is generated from it), or `qrImage: "assets/telegram-qr.png"` for a supplied QR image. Leave both empty to omit the block. |
| Scene timing, narration timing, SFX cue points | `src/data/timeline.json` (then `npm run sound` and `npm run srt`) |
| Narration audio | Put `VO01.wav`…`VO09.wav` (or `full.wav`) in `public/audio/voiceover/`, set `voiceoverMode` in `src/data/audio.ts` |
| Replace a silhouette with real footage | Put the clip in `public/footage/`, set its slot in `src/data/footage.ts` |
| Colours and fonts | `src/styles/theme.ts` |

## Arabic text rules used throughout

- Every Arabic string is rendered as one run inside `dir="rtl" lang="ar"`, so the browser's
  shaping engine joins letters correctly. Animations reveal text with right-to-left soft masks
  and never split words into letters.
- No `letter-spacing` is applied to Arabic.
- No Quranic verse is shown, paraphrased or synthesised anywhere in the film.
